TW Stock 觀察與趨勢分析功能規格

一、目標
建立一個台股觀察及分析功能，協助使用者快速判斷:
1. 哪些股票近期偏強
2. 哪些股票趨勢轉弱
3. 哪些股票基本面與技術面同時改善

這個功能是「趨勢觀察」工具，不是保證漲跌的預測器。目標是提高判讀效率，降低只看單一指標造成的誤判。

二、資料來源
host https://openapi.twse.com.tw/v1

可先使用以下 TWSE API:
1. 上市公司每日重大訊息
/opendata/t187ap04_L

2. 上市個股日本益比、殖利率及股價淨值比（依代碼查詢）
/exchangeReport/BWIBBU_ALL

3. 上市個股日收盤價及月平均價
/exchangeReport/STOCK_DAY_AVG_ALL

4. 投資理財節目異常推介個股
/Announcement/BFZFZU_T

5. 每 5 秒委託成交統計
/exchangeReport/MI_5MINS

6. 集中市場融資融券餘額
/exchangeReport/MI_MARGN

7. 上市個股日本益比、殖利率及股價淨值比（依日期查詢）
/exchangeReport/BWIBBU_d

三、MVP 功能
先做三個核心模組:

1. 股票觀察清單
- 可加入自選股
- 顯示代號、名稱、收盤價、月均價、本益比、殖利率、股價淨值比
- 顯示今日偏多 / 中性 / 偏空

2. 趨勢分析卡
每支股票建立一張分析卡，至少包含:
- 價格相對月均價
- 殖利率是否具吸引力
- 本益比是否過高
- 是否有重大訊息
- 是否有異常推介風險
- 融資融券是否異常增加

3. 趨勢分數
以 0 到 100 分表示後續偏多機率，不直接寫成「一定會漲」。

建議分數區間:
- 70 到 100: 偏多觀察
- 40 到 69: 中性整理
- 0 到 39: 偏空或風險升高

四、趨勢判斷邏輯
可先做簡化版規則模型，後續再升級。

1. 技術面
- 收盤價 > 月平均價: +20
- 收盤價 < 月平均價: -20
- 5 秒成交統計放大且價格走強: +10
- 量增但價格走弱: -10

2. 基本面
- 本益比低於同類平均: +10
- 殖利率高於市場平均: +10
- 股價淨值比過高: -10

3. 籌碼面
- 融資快速增加但股價未同步上漲: -15
- 融券增加且股價轉強: +10

4. 消息面
- 有正向重大訊息: +15
- 有負向重大訊息: -20
- 出現在異常推介名單: -25

五、畫面設計
首頁可分成三區:

1. 市場總覽
- 上市強勢股數
- 弱勢股數
- 今日異常推介警示

2. 自選股觀察表
- 股票代號
- 股票名稱
- 趨勢分數
- 偏多 / 中性 / 偏空
- 關鍵原因摘要

3. 單一股票分析頁
- 基本資料
- 趨勢分數
- 指標拆解
- 近期重大訊息
- 風險提醒

六、輸出文案範例
2330 台積電
- 趨勢分數: 78
- 判斷: 偏多觀察
- 原因: 股價高於月均價、殖利率穩定、近期無異常推介、重大訊息中性偏正向

2603 長榮
- 趨勢分數: 42
- 判斷: 中性整理
- 原因: 殖利率具吸引力，但價格尚未明顯站上月均價，短線方向仍需觀察

七、風險提醒
- 任何模型都不能保證未來漲跌
- 重大訊息的文字判讀容易有誤差
- 僅使用單日或少量資料時，訊號容易失真
- 若要提升可靠度，後續應加入歷史資料回測

八、下一步實作建議
第一階段:
1. 建立 TWSE API 抓取模組
2. 建立股票基本資料整併模組
3. 建立趨勢分數計算函式
4. 輸出觀察清單與分析結果

第二階段:
1. 加入歷史資料儲存
2. 加入移動平均、均量、波動度
3. 加入回測功能
4. 調整分數權重

第三階段:
1. 加入新聞情緒分析
2. 加入產業比較
3. 加入通知與警示
4. 加入 AI 摘要說明

九、建議的第一版技術切法
如果專案要快速起步，可先拆成:
- data: 負責抓取 TWSE API
- normalize: 將欄位整理成統一格式
- scoring: 計算趨勢分數
- watchlist: 產出自選股分析結果
- ui: 顯示列表與個股分析卡

十、建議先做的版本
先不要直接做「預測漲跌」模型，先做「趨勢觀察 + 風險提示」版本會更穩。

原因:
- 較容易解釋
- 較容易除錯
- 較容易逐步驗證
- 對使用者也比較可信

十一、目前成果 Demo 指南
如果要快速看目前 MVP，建議依照以下方式測試。

1. 打開 Web 畫面版
執行:
python3 app.py --serve

瀏覽器打開:
http://127.0.0.1:8000

可看到:
- 自選股觀察表
- 趨勢分數
- 偏多 / 中性 / 偏空判斷
- 個股分析頁
- 近期重大訊息與風險提示

2. 先試離線示範資料
執行:
python3 app.py --offline-sample --serve

適合用途:
- 先確認畫面流程
- 測試自選股切換
- 驗證評分邏輯與頁面呈現

3. 首頁建議先操作的功能
- 在輸入框輸入股票代號，例如 2330,2603,0050
- 點選「使用示範資料」或「切換 TWSE Live」
- 點股票代號進入個股分析頁
- 觀察分數、原因、重大訊息與籌碼資訊

4. 歷史資料 API 測試
執行:
python3 app.py --stock-day --stock-no 2330 --date 20250101

用途:
- 驗證 TWSE STOCK_DAY API 已可收到 response
- 查看單一股票某月份的每日成交資訊
- 作為後續走勢圖與歷史分析的資料來源

5. 目前已完成的功能
- TWSE API 串接
- 資料正規化
- 趨勢分數計算
- 自選股觀察清單
- 個股分析頁
- Web UI 基本操作
- STOCK_DAY 歷史資料測試

6. 目前還沒做的功能
- 歷史走勢圖
- 回測
- 新聞情緒分析
- 股票名稱搜尋與自動補全
- 通知與警示
